@AGENTS.md

Before doing any work in this repo, read AUDTHB-project-status.md in the
repo root. It's the actively maintained source of truth for what's built,
what changed and why, and current model/forecast versions — kept in sync
across whichever machine/session last touched the code, not just the one
you're in now. Re-read it after a `git pull` that moves HEAD, since it can
change without you. If your work changes what it describes (new workflow
step, recalibrated constant, rebalanced weight, new data source), update
it as part of that work, not as an afterthought -- same standard the file
itself already holds to.
